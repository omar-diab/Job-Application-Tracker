# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ |

## Report a security problem

**Please do not open a public issue for security problems.**

Report it privately on GitHub:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and which version you used.

You will get an answer as soon as possible, usually within 7 days. When the problem is fixed, a new version will be released and you will be credited (if you want).

## What counts as a security problem

For example:

- Text from a web page or a CSV file that can run code or inject HTML in the popup or the dashboard.
- A way for a website to read or change the jobs saved by the extension.
- Any data that leaves the user's computer.
